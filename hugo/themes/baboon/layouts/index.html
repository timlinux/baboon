Master your typing with beautiful practice. Track your progress, improve your speed, and type like a pro.

Why Baboon?

⌨️

Beautiful Interface

Large block letters with real-time colour feedback. See your progress instantly as you type.

📊

Detailed Statistics

Track WPM, accuracy, finger stats, bigram timings, and more. Understand your typing patterns.

🎯

Adaptive Practice

Words are weighted based on your weak letters. Practice what you need most.

🖥️

Terminal & Web

Use the beautiful TUI or the modern web interface. Your stats sync between both.

🔒

Privacy First

All data stored locally. No accounts, no tracking, no cloud required.

🚀

Cross-Platform

Works on Linux, macOS, and Windows. Built with Go for speed and reliability.

Quick Start

# Install with Go
$ go install github.com/timlinux/baboon@latest

# Or download a binary from GitHub releases
$ wget https://github.com/timlinux/baboon/releases/latest/download/baboon-linux-amd64

# Start typing!
$ baboon
